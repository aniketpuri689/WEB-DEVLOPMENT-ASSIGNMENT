Topic 16: CSS Transforms & Hover Transitions

Notes from Class:

  • Note: We did NOT study @keyframes! Only transform and transition on :hover.
  • transform functions:
    • skewX(-15deg);: Slants the box.
    • rotate(10deg);: Turns the box.
    • scale(1.1);: Zooms the box slightly.
    • translate(10px, 0);: Moves the box position.
  • transition: 0.3s;: Makes the hover animation smooth instead of sudden jump.
  • :hover: Action when mouse moves over the element.
