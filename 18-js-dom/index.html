Topic 18: JavaScript DOM Basics

Notes from Class:

  • DOM: Document Object Model. Browser treats HTML tags as objects that JS can find and change.
  • Selectors we learned in class:
    • document.getElementById("myId"): Finds one element by its ID.
    • document.getElementsByClassName("myClass"): Finds elements by class name.
    • document.querySelector(".myClass"): Finds first match using CSS selector.
    • document.querySelectorAll("p"): Finds all matching tags.
  • Changing text: element.innerText = "new text"
  • Changing style: element.style.color = "red"
  • Click action: element.onclick = function() { ... }
  • Boundary rule: NO async code (no promises, no fetch, no async/await).
