Topic 09: CSS Basics (Introduction & Syntax)

Notes from Class:

  • CSS: Cascading Style Sheets. Gives colors, borders, and looks to plain HTML.
  • Syntax:
    selector { property: value; }
    Example: h1 { color: blue; }
  • Teacher explained 3 ways to write CSS:
    1. Inline: inside tag like style="color:red;" (avoid).
    2. Internal: inside <style> in head.
    3. External: in separate style.css file linked with <link rel="stylesheet" href="style.css"> (best way!).
