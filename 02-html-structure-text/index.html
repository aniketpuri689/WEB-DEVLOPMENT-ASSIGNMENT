Topic 02: HTML Structure & Text Tags

Notes from Class:

  • <!DOCTYPE html> tells the browser this is modern HTML5.
  • <html> wraps everything. <head> has page title. <body> has everything we see.
  • Headings go from <h1> (biggest) down to <h6> (smallest). Teacher said only use one h1 per page.
  • <p> makes a paragraph.
  • Void tags have no closing tag: <br> (new line) and <hr> (horizontal line).
  • Comments: <!-- this is a note, browser won't show it -->.
