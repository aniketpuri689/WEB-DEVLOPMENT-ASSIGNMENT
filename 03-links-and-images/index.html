Topic 03: Links & Images

Notes from Class:

  • <a href="..."> is an anchor tag to make links.
  • target="_blank" makes the link open in a new tab.
  • Absolute Link: Full link with https:// (e.g. to Google).
  • Relative Link: Link to our own file on computer (e.g. ../index.html).
  • mailto: link opens email app.
  • <img> has no closing tag.
    • src: Where the picture is saved.
    • alt: Text description if picture doesn't load (mandatory).
    • width and height: Sets size in pixels.
