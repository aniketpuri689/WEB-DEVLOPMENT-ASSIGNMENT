Topic 04: HTML Lists

Notes from Class:

  • <ul> = Unordered list (bullet points). Order doesn't matter.
  • <ol> = Ordered list (numbered 1, 2, 3). Can use type="A" for letters or type="I" for Roman numerals.
  • <li> = List item (goes inside ul and ol).
  • <dl> = Description list. <dt> is the term/word, <dd> is the explanation.
  • Nested list = putting a list inside another list.

1. Bullet List (Unordered):

  • Notebook
  • Pen
  • Laptop

2. Numbered List (Ordered):

  3. Write HTML

With letters (type="A"):
