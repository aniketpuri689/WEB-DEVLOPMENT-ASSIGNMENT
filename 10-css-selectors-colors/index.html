Topic 10: CSS Selectors & Colors

Notes from Class:

  • Element selector: p { ... } (changes all p tags).
  • Class selector: .my-class { ... } (starts with a dot, can be reused on any tag).
  • ID selector: #my-id { ... } (starts with a hash, only for one unique element).
  • Attribute selector: input[type="text"] { ... }.
  • Grouping: h4, h5 { ... } (comma separated).
  • Colors:
    • Named: red, blue
    • HEX: #ff0000
    • RGB: rgb(255, 0, 0)
    • RGBA: rgba(255, 0, 0, 0.4) (has transparency)
