Topic 05: Semantic HTML Elements

Notes from Class:

  • Semantic means tags that describe what they contain, instead of using normal <div> for everything.
  • Good for screen readers (for blind users) and search engines (SEO).
  • Tags we learned:
    • <header>: Top banner or title area.
    • <nav>: Links menu.
    • <main>: Main center content (only one main per page).
    • <section>: A group of related stuff.
    • <article>: A stand-alone story or blog post.
    • <aside>: Side box or extra notes.
    • <footer>: Bottom footer with copyright.
