Topic 01: How the Web Works (My Class Notes)

Notes from Teacher's Lecture:

  • Internet vs Web: The internet is the physical cables and connected computers. The web is just the web pages we open on it. (Internet = road, Web = cars).
  • Client & Server:
    • Client: My browser (like Chrome) that asks for a website.
    • Server: The computer sitting somewhere 24/7 that keeps the website files and sends them to us.
  • Request and Response: Browser sends a Request → Server sends back a Response with the HTML page.
  • URL: Web address. Example: https://google.com/search.
  • DNS: The internet's contact book. Turns English names like google.com into IP numbers like 142.250.190.46 so computers can find each other.
  • HTTP Methods:
    • GET: Used when we normally open or search a page (reading data).
    • POST: Used when submitting secret data like a password or registration form.
  • HTTP Status Codes:
    • 200 OK: Everything loaded fine.
    • 404 Not Found: Wrong link or deleted page.
    • 500 Error: Server problem.
  • Browser Rendering:
    Browser reads HTML → makes DOM tree.
    Browser reads CSS → makes CSSOM tree.
    Combines them to draw the pixels on our screen.
