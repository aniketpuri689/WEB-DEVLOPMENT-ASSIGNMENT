Topic 06: HTML Tables

Notes from Class:

  • <table border="1"> starts the table. (Teacher told us border="1" makes lines visible in pure HTML).
  • <tr> = Table Row.
  • <th> = Table Header (bold and centered).
  • <td> = Table Data cell.
  • Structure tags: <thead>, <tbody>, <tfoot>.
  • colspan="2": Merges columns horizontally.
  • rowspan="2": Merges rows vertically.
