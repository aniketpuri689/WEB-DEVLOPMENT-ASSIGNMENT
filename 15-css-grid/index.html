Topic 15: CSS Grid Layout

Notes from Class:

  • Flexbox is 1D (row or column). CSS Grid is 2D (handles both rows and columns at the same time).
  • display: grid; goes on parent container.
  • grid-template-columns: 1fr 1fr; makes 2 equal columns (fr means fraction of space).
  • gap: 10px; puts space between cells.
