## 📌 Syllabus & Practical Project Overview

This repository contains my personal notes and hands-on beginner code files created as per my college syllabus.

### Key Rules Followed:
1. **Separation of Files:** Every topic is in its own single folder.
2. **No Unnecessary CSS:** Pure HTML topics (01 to 08) and JS basics (17) do not have unnecessary CSS; they use plain HTML as taught in the first half of the course.
3. **External CSS Only:** Topics 09 through 16, the basic portfolio, and the index page use pure external stylesheets (`style.css`). No internal `<style>` tags.
4. **Only Real-World Useful Projects Included:**
   - **Topic 06 (Tables):** College Semester Marksheet & Weekly Class Timetable (with `rowspan` and `colspan`).
   - **Topic 07 (Forms):** Complete College Student Admission & Registration Form (with all input types: text, email, password, number, date, radio, checkbox, dropdown, file upload, textarea, submit/reset).
   - **Topic 18 (DOM):** Interactive Student Attendance Click Counter (+ / -) & Text Color Switcher.
   - **`basic-portfolio/`:** A very very basic student portfolio with About Me, Skills, Coursework Project links, and Contact Form.
5. **Strict Scope Exclusions:**
   - Excluded `@keyframes` animations (only `skew`, `rotate`, `scale`, and `:hover` transitions were used).
   - Excluded Asynchronous JavaScript (no promises, fetch, or async/await — only basic JS and DOM selectors by ID/class/querySelector).
