Topic 17: JavaScript Basics

Notes from Class:

  • JavaScript: Programming language that brings math, logic, and actions to web pages.
  • Variables:
    • let: Normal variable whose value can change.
    • const: Fixed value that never changes.
    • var: Old way, avoid using.
  • Data Types: String ("hello"), Number (10, 20.5), Boolean (true/false), Undefined, Null.
  • Operators: +, -, *, /, %, ==, ===, &&, ||.
  • Conditionals: if (marks >= 40) { ... } else { ... }.
  • Loops: for (let i = 1; i <= 5; i++) repeats code.
  • Functions: Reusable piece of code: function add(a, b) { return a + b; }.
