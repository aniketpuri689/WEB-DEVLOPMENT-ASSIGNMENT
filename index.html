01 01-web-basics/index.html How the Web Works: Explains in simple words the difference between the Internet (cables & network) and the Web (pages we open). Covers the Client-Server model, Request-Response cycle, URL structure, DNS (Internet phonebook converting names to IP addresses), HTTP methods (GET for viewing, POST for sending forms), status codes (200 OK, 404 Not Found, 500 Server Error), and how browsers render pages by making DOM and CSSOM trees. Open File 01
02 02-html-structure-text/index.html HTML Structure & Text Tags: Demonstrates the basic skeleton of an HTML document (<!DOCTYPE html>, <html>, <head>, <body>). Shows all heading levels from <h1> to <h6>, paragraphs <p>, line breaks <br>, divider line <hr>, and text formatting tags: bold (<b>, <strong>), italic (<i>, <em>), underline (<u>), highlight (<mark>), subscript (H<sub>2</sub>O), and superscript (10<sup>2</sup>). Open File 02
03 03-links-and-images/index.html Links & Images: Covers creating hyperlinks using the anchor tag <a>, using href, setting target="_blank" to open links in a new browser tab, understanding absolute links (external websites) vs relative links (local files on our computer), and mailto: links. Shows how to add photos using the <img> tag with src, width, height, and the mandatory alt text attribute. Open File 03

Open File 04

Open File 07

09 09-css-basics/ CSS Basics & External Stylesheet: Introduces CSS, its syntax rule (selector { property: value; }), explains the 3 ways to write CSS (inline, internal, external), and demonstrates linking a separate style.css file to HTML using <link rel="stylesheet" href="style.css">. Open File 09
10 10-css-selectors-colors/ CSS Selectors & Colors: Covers targeting elements using tag names, class selectors (.class), ID selectors (#id), attribute selectors, and comma grouping. Explains CSS color models: named colors (red, blue), HEX codes (#ff0000), RGB, and RGBA with transparency/opacity. Open File 10
11 11-typography-cascade/ CSS Typography & Cascade: Demonstrates font styling (font-family, serif vs sans-serif vs monospace, font-size, bold weights, line-height, letter-spacing, text-align). Demonstrates CSS Cascade and Specificity rules (Inline 1000 > ID 100 > Class 10 > Element 1) showing which style wins when rules conflict. Open File 11
12 12-box-model/ CSS Box Model: Explains the 4 layers of every HTML element: Content, Padding (inside space), Border (edge outline), and Margin (outside distance). Demonstrates why box-sizing: border-box is essential to prevent boxes from unexpectedly breaking or expanding. Open File 12
13 13-display-position/ Display & Positioning: Covers display: block (full line), inline (flows with text), inline-block (in-line but accepts width/height), and none (hides). 14 14-flexbox/ CSS Flexbox Layout: Using display: flex to make child items align horizontally in rows or vertically in columns. Covers flex-direction, justify-content: space-between, align-items: center, gap for spacing, and flex-wrap. Open File 14
15 15-css-grid/ CSS Grid Layout: Introduces 2-dimensional layouts (handling rows and columns together). Demonstrates display: grid, grid-template-columns: 1fr 1fr; (using fraction units), and cell gap. Open File 15
16 16-transforms-transitions/ CSS Transforms & Hover Transitions: Covers 2D transforms (skewX(-15deg) to tilt, rotate(10deg), scale(1.1), and translate). Demonstrates smooth transition: 0.3s when hovering with :hover. (Strictly excluded @keyframes as specified in syllabus). Open File 16
17 17-js-basics/ JavaScript Basics: Introduces JavaScript programming: declaring variables with let, const, and var, data types (string, number, boolean, undefined, null), arithmetic and comparison operators (===, >=), if-else decision making, for loops, and writing simple functions. Open File 17
