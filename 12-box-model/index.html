Topic 12: CSS Box Model

Notes from Class:

  • Every tag is treated as a rectangular box with 4 layers (inside to outside):
    1. Content: The actual text or photo.
    2. Padding: Space inside the box (between text and border).
    3. Border: Outline line around the box.
    4. Margin: Space outside the box (distance from other elements).
  • box-sizing:
    • content-box (Default): Padding and border make the box bigger than width you set!
    • border-box: Padding and border stay inside the width you set. Much better!

Demonstration:

I am a box with 10px margin, 2px border, and 15px padding!
I am width 250px with box-sizing: border-box. My size stays exactly 250px!
