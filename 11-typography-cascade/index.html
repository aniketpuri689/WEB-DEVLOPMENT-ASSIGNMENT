Topic 11: CSS Typography & Cascade

Notes from Class:

  • font-family: Sets font (e.g. Arial, Georgia, Courier). Always put fallback like sans-serif.
  • font-size: Text size (px).
  • font-weight: bold; makes text bold.
  • text-align: left, center, right.
  • line-height: Spacing between lines (e.g. 1.6).
  • Cascade & Specificity: If two CSS rules fight for the same element, who wins?
    Inline style (1000) > ID (100) > Class (10) > Element tag (1). Highest points win!
