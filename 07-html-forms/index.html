Topic 07: HTML Forms & Complete Input Types

Notes from Class:

  • <form action="..." method="POST"> is used to collect user details.
  • <label for="idName"> connects the label text to the input with matching id="idName".
  • Radio button (type="radio"): User can only pick ONE option. All options must have the exact same name!
  • Checkbox (type="checkbox"): User can pick multiple options (or none).
  • <select> & <option> makes a dropdown menu.
  • <textarea> makes a big box for multiple lines of text.
  • required makes the user fill it before pressing submit.
