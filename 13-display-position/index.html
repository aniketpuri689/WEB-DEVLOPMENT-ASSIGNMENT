Topic 13: CSS Display & Positioning

Notes from Class:

  • Display:
    • block: Takes full line width (div, p).
    • inline: Sits on same line, width/height don't work (span, a).
    • inline-block: Sits on same line, BUT we can give width and height!
    • none: Hides element.
  • Positioning:
    • static: Normal order.
    • relative: Moves slightly from its normal spot using top/left.
    • absolute: Pinned inside parent element having position: relative.
    • fixed: Glued to screen, stays even when scrolling.
    • sticky: Sticks when scrolled to top.
