Topic 14: CSS Flexbox Layout

Notes from Class:

  • Put display: flex; on parent box so child boxes sit side by side.
  • flex-direction: row; (horizontal) or column; (vertical).
  • justify-content: space-between; spreads boxes across main row.
  • align-items: center; centers boxes vertically.
  • gap: 10px; simple space between boxes.
  • flex-wrap: wrap; lets boxes wrap to next line on small screens.
